IoT Landslide Early Warning & Telemetry System

Research & Embedded Telemetry

1. Problem & Innovation

Engineered a slope monitoring system that prevents false alarms by isolating ambient surface noise (heavy rainfall) from genuine subsurface ground shear displacement.

2. Mechanical Coupling & Dampening

Coupled an MPU6050 6-axis IMU to a 0.5m subsurface probe, attenuating superficial noise to 0.08g while maintaining high sensitivity to deep shear (0.58g).

3. Signal Processing & State Engine

Implemented rolling Acc_RMS calculations (50 Hz) on dual ESP32 nodes to isolate static gravity vectors and classify real-time risk tiers (SAFE → CAUTION → RED ALERT).

4. Off-Grid Telemetry & Dashboard

Integrated 433 MHz LoRa (SX1278) for long-range node-to-base telemetry, combined with local OLED/buzzer alerts and real-time REST API web dashboards.

Edge AI Vibration Anomaly Detection System

TinyML & Predictive Maintenance

1. Overview & System Goal

Engineered an on-device predictive maintenance solution using ESP32 and MPU6050 IMU to detect abnormal mechanical vibrations in machinery in real time.

2. Data Pipeline & Spectral Features

Streamed raw tri-axial accelerometer data over I2C to ESP32. Extracted frequency-domain spectral features using custom Python serial acquisition scripts.

3. TinyML On-Chip Inferencing

Trained a K-Means Anomaly Detection model via Edge Impulse. Deployed optimized C++ inferencing firmware directly onto ESP32 to compute anomaly scores locally.

4. Structural Mounting Rigidity

Designed a rigid, low-resonance sensor mount to ensure uncompromised vibration transmission from machinery directly into the IMU sensing plane.
